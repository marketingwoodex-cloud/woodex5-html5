# Content guide

Everything a non-developer needs to change lives in `src/data/`. No component
contains its own copy. This is the theme's frontend API — treat it as the CMS.

| File | What it holds | Pages it feeds |
| --- | --- | --- |
| `site.js` | Brand name, contact details, addresses, hours, socials, CTA labels, SEO defaults, headline stats | Every page (header, footer, metadata, schema) |
| `services.js` | 17 services: lede, body, deliverables, duration, pricing, sector, icon, FAQs | `/service`, `/services/<slug>`, mega menu |
| `projects.js` | 9 projects: brief, approach, outcome, metrics, gallery, testimonial, **spec sheet** | Portfolio layouts, case studies, homepage reels |
| `articles.js` | 9 articles with block-based bodies, topics, authors | Journal layouts, article pages, RSS |
| `content.js` | Team, offices, milestones, awards, pricing packages, add-ons, FAQs, testimonials, clients, process steps | About, team, careers, pricing, FAQ, process, contact |
| `navigation.js` | Primary nav + six mega panels, footer columns, legal links | Header, drawer, footer, sitemap |
| `images.js` | 111 image slots: canonical path, alt text, aspect ratio | Every image |

## Rebrading in one file

Editing `site.js` alone updates: the wordmark and brand text, phone (label **and**
`tel:` href), email, both studio addresses, opening hours, response promise, social
links, both CTA labels, the counters shown on several pages, and the default SEO
title/description.

## Writing new content

### Add a project

```js
// src/data/projects.js
{
  slug: 'new-project',                 // becomes /project/new-project
  title: 'New Project',
  sector: 'residential',               // must match an entry in `sectors`
  location: 'DHA Phase V, Lahore',
  year: 2026,
  area: '4,200 sq ft',
  duration: '18 weeks',
  services: ['Turnkey Fit-Out'],
  excerpt: 'One sentence a client would repeat to a friend.',
  cover: '/images/projects/new-project-cover.jpg',
  gallery: ['/images/projects/new-project-01.jpg'],
  featured: true,                      // appears in homepage reels
  span: 'wide',                        // masonry layout weight
  challenge: '…', solution: '…', result: '…',
  metrics: [{ value: '18', unit: 'weeks', label: 'Design and build' }],
  testimonial: { quote: '…', author: '…', role: '…' },
  spec: {
    structure: '…', rooms: '…', systems: '…',
    compliance: '…', tolerance: '…',
    materials: [{ name: 'Oak veneer', note: 'Sealed satin' }],
    notes: '…',
  },
  colour: '#fcf2e8',
}
```

Then add the two image slots to `src/data/images.js` (cover + gallery) and run
`npm run images` — placeholders are generated for anything missing.

### Add an article

Articles use a **block body**, which is the same shape a headless CMS returns:

```js
body: [
  { type: 'h2', text: 'Where the cost actually sits' },
  { type: 'p', text: '…' },
  { type: 'list', items: ['…'], ordered: false },
  { type: 'quote', text: '…' },
  { type: 'image', src: '/images/journal/x.jpg', alt: '…', caption: '…' },
  { type: 'table', head: ['Item', 'Cost'], rows: [['Joinery', '38%']] },
  { type: 'callout', tone: 'warn', title: '…', text: '…' },
  { type: 'divider' },
]
```

Supported blocks: `h2 · h3 · p · list · quote · image · gallery · table · callout · divider · html`.

### Add a service

Add to `services` with a `slug`, `title`, `shortTitle`, `group` (one of
`residential | commercial | hospitality | retail | specialist | fitout`), `lede`,
`summary`, `body[]`, `deliverables[]`, `duration`, `startingAt`, `icon`.
A page appears at `/services/<slug>` on the next build.

## Where not to edit

- `src/generated/image-map.json` — build artefact, regenerated automatically.
- `templates-lib/` — generated by `npm run templates`; edit `src/sections/` instead.
- Anything in `dist/` — build output.
