Style guide

Identity, type and components

The complete visual system: colour tokens, the type scale, spacing rhythm, buttons, cards, forms, navigation patterns and every section in the library — documented against live examples.

to place several. swatches → palette chips (paletteTitle, paletteText, swatches[{name,token,hex,use}]) types → type specimens (typeTitle, typeText, types[{class,label,size,family,use}]) spaces → spacing scale (spaceTitle, spaceText, spaces[{token,value,use}]) buttons → live button set (btnTitle, btnText, btnVariants[]) comps → class contracts (compTitle, compText, comps[{k,v}]) secList → section library (secTitle, secText, secList[{k,v}]) ========================================================================== }}
01 / Colour

Colour tokens

Five base colours plus four surface themes. Every component reads tokens, never literals, so a rebrand is a single file change.

  • Canvas --c-canvas #F8F3EA Page background, cards, section fills
  • Ink --c-ink #14110D Body text, headings, inverse surfaces
  • Clay --c-clay #A94E2B Primary accent, links, active states
  • Clay hover --c-clay-strong #8E3F22 Hover and pressed accent states
  • Walnut --c-walnut #4A3527 Warm dark sections, footer
  • Brass --c-brass #B9922E Micro accents: rules, badges, numerals
  • Charcoal --c-muted #5C554B Secondary text, captions, meta
  • Silver --c-line #DED3C2 Borders, dividers, input outlines

05 / Contracts

Component contracts

Class names are the public API of the theme. Sections expose a single .s-* root; everything inside is namespaced beneath it.

.s-* section roots
One per section template — the styling and JS hooks attach here.
.btn / .btn--*
Pill buttons with sliding dual labels and arrow medallion.
.eyebrow
Mono label with a leading rule; used above every section title.
.media / .media--arch
Image wrapper with an arch-top mask variant.
.card / .card--*
Project, service, post and testimonial cards.
.field / .field--*
Form controls with floating labels and inline validation states.
.nav / .drawer
Header navigation and the full-screen mega menu overlay.
.marquee / .ticker
Seamless scrolling bands at display and small sizes.
[data-render] + [data-template]
Client-side render slots for content arriving from the JSON API.
window.Woodex
The single global: utilities, API client, motion registry and section initialisers.
