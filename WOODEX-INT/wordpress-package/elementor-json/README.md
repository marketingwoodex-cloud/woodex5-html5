# Elementor JSON Import Pack

Elementor template exports must be generated from the connected WordPress/Elementor environment because the exact Elementor, XPRO, theme, and widget schema is site-specific.

The import order is documented in `../../wordpress-elementor-complete-system.md`.

Use native Elementor Containers only. Do not import or create Inner Sections, Atomic Editor elements, or Elementor Pro widgets.

Expected final exports:

- site settings
- global colors
- global fonts
- XPRO header
- XPRO footer
- homepage
- services index
- service detail
- portfolio index
- project detail
- process
- journal index
- article detail
- contact
