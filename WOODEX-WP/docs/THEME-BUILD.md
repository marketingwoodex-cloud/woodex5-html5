# Theme Build

Created new WordPress parent and child theme packages from the Woodex HTML5 source because the original theme.zip and child.zip were unavailable.

Files:

- `wordpress-package/woodex-parent-theme.zip`
- `wordpress-package/woodex-child-theme.zip`
- `wordpress-package/woodex-core-plugin.zip`

Install parent first, then child. The child `Template:` value is `woodex-parent`.

These are Elementor-friendly theme scaffolds. Elementor page designs, XPRO header/footer templates, WPForms configuration, and one-click import content are configured after WordPress and the required plugins are installed.
