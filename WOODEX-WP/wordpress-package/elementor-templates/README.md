# Elementor Template Import Folder

Final Elementor exports must be exported from the connected WordPress/Elementor site because each Elementor/XPRO installation contains site-specific IDs and widget schemas.

Expected templates:

- header.json
- footer.json
- homepage.json
- services-index.json
- service-detail.json
- portfolio-index.json
- project-detail.json
- process.json
- journal-index.json
- article-detail.json
- contact.json

Use Containers only. Do not use Inner Sections, Atomic Editor, Atomic Elements, or Elementor Pro widgets.
