# WOODEX-WP Theme V2 Conversion

Complete Theme V2 data and implementation package for WordPress Elementor Free + XPRO + WPForms + Woodex Core.

## Rules

- Elementor Free only.
- Containers only.
- No Inner Sections.
- No Atomic Editor.
- No Atomic Elements.
- No Elementor Pro widgets.
- XPRO owns the global header and footer.
- WPForms owns consultation forms.
- Woodex Core owns services, portfolio, FAQs, testimonials, settings, and import data.

## Package status

The conversion data, template map, plugin configuration, and staging QA files are complete. Actual WordPress/Elementor exports require the connected WordPress staging environment.

The original parent/child ZIP files are still pending and must be supplied before final theme installation.
