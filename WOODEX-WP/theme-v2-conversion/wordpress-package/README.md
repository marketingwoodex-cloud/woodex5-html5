# Theme V2 WordPress Conversion Package

This folder contains the complete upload/import structure for Theme V2:

- `demo-import/` — one-click import manifest and safety notes
- `elementor-templates/` — Elementor Containers-only template import notes
- `theme/` — parent and child theme source
- `wp-content/plugins/woodex-core/` — Woodex Core plugin source
- `woodex-parent-theme.zip`
- `woodex-child-theme.zip`
- `woodex-core-plugin.zip`

Rules: Elementor Free, native widgets, Containers only, no Inner Sections, no Atomic Editor/Elements, no Elementor Pro widgets.
