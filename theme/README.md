# Woodex Master Theme

A complete, multi-page HTML5 master theme for **Woodex Interior** — premium interior architecture, fit-out and joinery studio (Lahore · Islamabad · Karachi).

**Original work:** every line of code, all copy and all imagery are original. The theme follows standard interior-website structure patterns; see [`../design.md`](../design.md) for the full PRD.

## Quick start

```bash
cd theme
python3 -m http.server 4174 --bind 0.0.0.0
# open http://localhost:4174
```

Static site — no build step required. Serve over HTTP (not `file://`) so the JSON content layer loads.

| Area | Files |

| Images | `assets/images/` — original AI-generated photography set |

## Customizing

1. **Content** → edit `assets/data/*.json`
2. **Look** → edit `assets/css/tokens.css`
3. **Structure** → reorder/copy sections from `templates/sections/`
4. **New detail pages** → add a JSON record, run `node build.mjs`

## Deployment

Any static host: GitHub Pages, Netlify, Vercel, Cloudflare Pages. Upload `theme/` as the site root. Point forms at Formspree/Netlify Forms via the form `action`.

## Before client launch

Replace placeholder contact details in `assets/data/site.json` (marked with zeros), connect the form endpoint, and run a Lighthouse pass against the checklist in design.md §13.
