Getting started

Run it, edit it, extend it

The Woodex Master Theme is static HTML + CSS + JS with a JSON content layer. No build step required — one optional script for SEO prerendering.

Quick start

  • cd theme
  • python3 -m http.server 4174 --bind 0.0.0.0
  • open http://localhost:4174

Serve over HTTP — opening files directly (file://) blocks the JSON content layer.

Optional prerender

  • node build.mjs

Writes static detail pages (project/, service/, blog/) and fills data-api grids for no-JS crawlers.

Editing content (no HTML)

Everything repeatable lives in assets/data/*.json — services, projects, articles, testimonials, pricing, FAQs, team, process, navigation and site settings. Change the JSON, refresh, done. The header, footer and mega menu rebuild themselves from navigation.json.

Adding a page

Copy the closest skeleton from templates/pages/, set data-header and data-footer on the body tag, and compose sections copied from templates/sections/. Reorder freely — sections are self-contained.

  • data-header — transparent · light · dark · centered · side
  • data-footer — classic · compact · cta

Adding a project, service or article

Add a record to the matching JSON file. It appears in every grid immediately (via the data layer), and node build.mjs generates its static page in project/, service/ or blog/.

Changing the look

Re-skin the entire theme from assets/css/tokens.css — colors, fonts, radius, spacing. Motion timing lives there too (--wx-ease, --wx-dur). The full design reference is design.md in the repository root.

Motion

  • data-reveal on any block — up · fade · left · right · zoom · blur · mask
  • data-reveal-delay="1–8" staggers by .12s
  • data-counter rolls numbers on scroll
  • .wx-marquee loops anything — add --slow or --reverse
  • data-parallax="0.15" drifts media on scroll

Forms

Forms validate and show success/error states locally. To actually collect submissions, point them at Formspree, Netlify Forms or your own endpoint in the form's action — see docs in design.md §12.

AI agents

AGENTS.md in the theme root carries the customization rules for Codex, Claude, Kimi or any coding assistant — what to edit, what never to touch.

Golden rule: content in JSON, structure in templates, skin in tokens. Break nothing else.
